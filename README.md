# bluDrive

Prototipo web tipo inDrive (React + TypeScript + Vite + Tailwind CSS v4), en versión azul.

Replica el flujo principal de un ride-hailing donde el pasajero propone su propio precio:

- Splash y login por número de teléfono
- Home con mapa y accesos a viajes/entregas
- Selección de origen/destino
- Pantalla para ofrecer tu propio precio (seña distintiva de inDrive)
- Búsqueda de conductores y listado de ofertas recibidas
- Viaje en curso con datos del conductor
- Calificación del viaje
- Historial de actividad y perfil

Todo el estado de la app es simulado en el cliente (sin backend), pensado como demo de UI/UX.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
